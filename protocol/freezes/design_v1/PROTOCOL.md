# Independent-integrator validation protocol, 2026-10-26

Status: **design locked; execution freeze pending input manifests and independent code audit**. Root has approved the design choices below before new outcome examination. This protocol adds experiments; it does not revise the historical calibration or pretend the original cohort was untouched. The machine-readable counterpart is `analysis_protocol.json`.

## 1. Questions, cohorts and claims

The primary new-cohort question is the size and direction of the paired difference between adaptive C and the competitive fixed weight 0.01 under corruption. The two retained endpoints are boundary-point RMS-TRE and any-centroid-error >3-mm failure frequency. We will report both, regardless of whether they favor the same estimator. We do not promise adaptive superiority, establish a new overall pass/fail hierarchy, claim that 50 cases provide 80% power, or change endpoints in response to the results.

Two cohorts remain separate throughout:

1. **Old independent-integrator cohort:** the original 50 assigned evaluation CTs, of which the same 47 passed the frozen synthetic-geometry checks. All 47 receive the new Siddon target experiment. The original three exclusions remain visible in coverage, without replacement or invented RMS. This is full eligible-cohort numerical-model sensitivity on exposed anatomy, not independent-patient validation.
2. **New public cohort:** identify 60 ordered candidate source units without inspecting registration outcomes; select the first 50 meeting frozen source/input criteria. The target of 50 is a resource decision. Screening must precede synthetic motion and optimization. Do not replace later geometric exclusions or unfavorable outcomes to maintain 50 successes. If fewer than 50 meet input requirements, disclose the shortfall before results rather than silently enlarge the source pool.

In the new cohort, call the independent unit a patient only when source metadata establish patient identity and overlap exclusion. Where only source-subject identity is documented, use that term and explain its limits. If patient linkage remains unknown, use CT-volume-level inference, state the independence assumption, and do not describe the result as verified unseen-patient generalization. A new public dataset name, different filenames or unequal voxel hashes do not prove different patients; the same patient may have different scans or be redistributed across datasets. Check original-source identifiers, available linkage and duplicate content against all old 75 cases. An unresolved overlap audit limits the independence claim even if computation proceeds.

Prefer one CT per verified patient. Select that CT before outcomes by a documented deterministic source-ID order. If multiple CTs must remain, average seeds within CT and CTs within patient, give each patient weight one, and resample complete patients. Retain all CTs/seeds from a patient in one cohort. Never pool the old and new cohorts to inflate precision or claim a larger independent validation set.

Record a candidate manifest with source DOI/release/split, stable source identifiers, verified linkage level, original filenames, hashes, overlap-audit evidence, input-screen decisions and reasons. Freeze all intersecting source IDs in SHA256(`ijcars-independent-validation-20261026-new-candidates-v1:` + stable source unit ID) order, with ID breaking any tie. Before downloading full CTs, prefilter on all five L1-L5 masks being nonempty and none touching the image boundary, and take the first 60 complete candidates. Root then checks CT/segmentation grid, affine, units, integrity and content/identity duplicates; the first 50 passing source-input QC in the frozen order are assigned. The remaining ten are input-completeness reserves only. Assign immutable case indices 0–49 in the final assigned order, before motion generation, and never renumber after geometry exclusions.

Input exclusion is allowed only for source/archive integrity failure, unusable affine/spacing, incomplete L1–L5 labels/coverage required by the task, documented old-cohort overlap, or a documented repeated patient after one scan has been selected. Criteria must be operationalized in the manifest before registration. Do not exclude difficult anatomy, large errors, slow optimization, a method failure, or a disappointing adaptive comparison. The first 50 input-eligible units are assigned; synthetic geometry is assessed afterward and cannot trigger replacement.

## 3. Frozen target and method definitions

Both cohorts use independent **float64 Siddon voxel-cell path-length integration at 512 × 512**, followed by the exact nonoverlapping 2 × 2 area mean to the original 256 × 256 detector. Match camera geometry and pixel-centre conventions to the original target pipeline. This differs from the earlier ten-case direct-256 Siddon sensitivity, which remains a separate historical result and does not count as completion of the new experiment.

Keep the original bone-selective proxy, source segmentation, views, motion model, photon count, Gaussian noise and blade-proxy rules. The old cohort reuses saved ground-truth transforms, centres, eligibility and original all-75 case indices; do not regenerate its motion from a reordered subset. Old motion/corruption and global-A seeds retain base 20261024; old candidate seeds retain base 20261025. The external cohort uses motion/corruption/global-A base **20361024** and candidate base **20361025**, each offset by 100000 from the original. New motion uses `default_rng(20361024 + 1009 * assigned_case_index)`, the original ordered draws of three global rotation-vector components, three global translations and four positive normalized joint weights, and the original index-based common motion sign. Five corruption repeats use the applicable cohort base plus `1009 * case_index + 12347 * repeat_index`, repeat indices 0–4. Global A uses the applicable cohort base plus `1009 * case_index`, then the original per-CMA-start offset. Both views use L1 if floor(case_index/2) is even, L5 otherwise; view-specific masks follow the original independently drawn detector-coordinate rule.

Corruption is a **controlled reference-based construction** in both cohorts. For the old cohort, retain the original trilinear clean512-to256 reference and direct256 trilinear component projections that determine masks, attenuation scales and per-view RNG starting states. For the external cohort, generate those same forms of trilinear references at the frozen ground-truth pose, using them only to define the corruption plan. Insert the independent Siddon clean image into that fixed attenuation/noise plan. Generate Poisson/Gaussian observations for the Siddon attenuation; do not paste the old residual onto the target. A per-view RNG starting state is fixed, but data-dependent Poisson draws can change subsequent random-stream consumption, so this does not assert identical Gaussian values. Save reference images, masks, scales, sampling states and hashes. The optimizer always receives the Siddon clean or its corrupted version. Disclose that corruption geometry/scaling shares the trilinear reference model; this controlled design does not remove all shared-model assumptions.

External input preprocessing retains the released CT/segmentation grid and affine, crops the union of L1–L5 plus a 3-mm physical margin while preserving world coordinates, and centres coordinates at the unweighted mean of the five vertebral centroids. Map source labels explicitly to internal labels20–24. Use the same five-label-masked proxy `clip(HU - 150, 0, 1800)`. There is no new parameter tuning or outcome-dependent resampling.

Each independent unit has one clean target and five corrupted targets sharing the same motion. Four methods use the exact same target bytes: B (zero prior), fixed 0.003, fixed 0.01, and adaptive with frozen maximum 0.01 and tau 0.01389625625827594. Keep 3°/3-mm prior scales. Do not refit tau, rerun parameter selection, select another maximum or gate execution using the new outcome labels. The historical development gate remains part of the frozen algorithm, not an acceptance test for the new cohort.

Recompute initialization and the shared candidate bank for each new target; the independent target changes the image objective, so reusing an old bank optimized on the original renderer would not be a matched end-to-end test. All four estimators share the A-derived start, four original deterministic perturbations, prior-free candidate optimization and common image-best winner. Candidate perturbation seeds are `candidate_base + 1009 * case_index + 7919 * k`, k=1–4, where candidate_base is 20261025 for the old cohort and 20361025 for the external cohort. Do not warm-start a method from another method’s final result. Keep original pyramids, objective normalization, Adam/L-BFGS settings, convergence/stagnation criteria and best-objective return behavior. Record configuration, code, native input, target, candidate and output hashes, as well as seed and case-index provenance.

Independent integration changes the target model while retaining CT-based proxy physics and cameras. It addresses numerical inverse-crime concerns but does not create clinical radiographs or eliminate every shared-model assumption. Display-only 1024 re-rendering does not count as a new registration experiment.

## 4. Primary endpoints and aggregation

For each vertebra, compute RMS displacement of the original deterministic sample of up to 1,000 boundary-voxel centres under estimated versus true transforms. Average the five vertebral RMS values. Do not change to the square root of the pooled five-vertebra mean-square error, an area-weighted mesh metric, a centroid RMS or a different surface sampler.

A target fails if **any of its five vertebral centroid errors is strictly greater than 3 mm**. Failure at exactly 3 mm is false. For corrupted results, average five target-level RMS values within the independent unit; separately average the five binary target-failure indicators. Do not threshold the average error and do not treat five repeats as independent patients. Clean outcomes use the one clean target and remain a separate analysis. Across verified patients, weight patients equally. CT-volume analyses must be explicitly labeled when linkage is not established.

The primary effect is the mean of matched unit-level differences, adaptive minus fixed 0.01. Negative values favor adaptive. Report RMS differences in millimetres and failure-frequency differences in percentage points, along with both methods’ means, independent-unit counts and repeated-target counts. Also report clean accuracy costs, distributional summaries, geometry/compute completion and fixed-0.003 comparisons. Thresholds 2, 4 and 5 mm remain descriptive sensitivity endpoints; none can replace the predeclared 3-mm endpoint.

## 5. Comparison priority, intervals and multiplicity

For **each cohort separately**, corrupted adaptive minus fixed 0.01 is the sole primary contrast, with the two retained endpoints. Provide ordinary pointwise 95% percentile bootstrap CIs and **97.5% marginal percentile CIs for each of these two endpoints**. Bonferroni then gives nominal family coverage of at least 95% if the marginal intervals achieve their nominal coverage; finite-sample bootstrap intervals are approximate, so this is not an exact coverage guarantee.

Predeclared secondary contrasts, in reporting order, are fixed 0.01 minus B; adaptive minus B; fixed 0.003 minus B; adaptive minus fixed 0.003; and fixed 0.01 minus fixed 0.003. Give pointwise 95% CIs and explicitly label these descriptive. The same contrasts on clean targets are descriptive and separate from the corrupted primary family. No familywise claim is made across secondary comparisons, clean conditions, additional thresholds or the two distinct cohorts. Do not select the most favorable significant contrast and describe it as proof of the best method.

There is **no new null-hypothesis significance test, joint superiority pass/fail rule, gate sequence, p-value ranking or noninferiority claim**. The historical two-endpoint definitions remain; the historical three-test procedure can still be described as history. This new design focuses on effect magnitude, uncertainty, competing endpoints and the competitive fixed comparator. A narrow interval favoring one endpoint does not settle the other endpoint; an interval spanning zero does not prove equivalence. The old observed effect cannot be treated as a guaranteed new effect or used to assert that 50 cases are powered.

## 6. Exact resampling rule

Follow the original `adaptive_analysis.py` aggregation: form paired differences for matched target/seed rows, then collapse repeats to equal unit means. Sort the final complete unit IDs lexicographically. Use `numpy.random.default_rng(20261024)` to generate 10,000 bootstrap index rows, each drawing n units with replacement from the n complete independent units. The same index matrix is reused across methods and endpoints within the cohort/condition. Each draw averages the paired unit differences selected by that row; it does not independently resample the two methods or individual seeds.

Use `numpy.quantile(draws, [0.025, 0.975], method='linear')` for pointwise 95% CIs. For the two primary corrupted endpoints, additionally use `[0.0125, 0.9875]` for 97.5% marginal CIs. Store unit IDs, unit-level endpoint means, paired differences, bootstrap seed/count and quantile levels so that every summary is auditable. The seed is reused for reproducibility, not selected from alternative seeds. Do not discard bootstrap draws because they contain no failures or yield zero differences. There is no class-count requirement for estimating the mean failure-frequency difference. Any AUROC diagnostic is descriptive, uses the original weighted/clustered rule, reports valid draw counts, and cannot change execution or calibration.

If all observed unit differences are identical, retain the empirical degenerate CI and label zero empirical variance. In particular, an all-zero failure sample can yield [0,0] from the nonparametric bootstrap; this does not show that population failure risk is zero or that methods are equivalent. Report the number of units and targets contributing failures and paired discordance. Do not add a post-hoc favorable test or change to a threshold with more events.

## 7. Missingness, exclusion and computational failure

Geometry is checked before registration under the unchanged rule. The old cohort retains its original three exclusions; new cohort exclusions are recorded without replacements. Accuracy is conditional on geometrically eligible targets. All-assigned pipeline success counts geometry exclusions as unsuccessful, with no invented RMS.

A transient infrastructure interruption may be resumed or retried using the identical target, inputs, seed, configuration and stopping rules. Retain retry logs. Do not change optimization settings to make a failed case converge. If a solver returns a finite best pose according to its frozen rule, evaluate that returned pose even if a diagnostic says numerical stagnation; a finite nonconverged result is not silently excluded. Persistent no-output/nonfinite execution is a computational failure, distinct from centroid failure.

For paired numerical RMS, use the same complete eligible-unit set across all four methods and all five corruption seeds. Report every omitted unit, method, missing seed and reason. Do not average only successful seeds. If persistent computation failures occur, describe this analysis as conditional on completion rather than full-cohort accuracy. Separately report the all-assigned composite pipeline success, treating geometry and computational failures as unsuccessful; do not conflate this composite with the pure >3-mm centroid-failure endpoint. Bounds or additional missing-data analyses require a transparent amendment and cannot hide the original completion counts.

Independently, if midpoint-quadrature convergence is assessed, vary its requested h/cap while holding interpolation/model/pose/detector fixed and report actual ray intervals; do not mix this with Siddon detector supersampling convergence. The predeclared engineering review flags are **relative L2 >0.005 or original NCC loss >0.0001 in any of the 20 selected case/view comparisons of 512-to256 versus 1024-to256**. They flag technical review rather than clinical correctness or a pass/fail standard for independent validation. If triggered, inspect geometry, precision and aliasing; a change to denser target sampling requires a new protocol version justified only by the old-development numerical diagnosis. Do not inspect the 47-case or external cohort method rankings to choose target sampling. A value below the flags supports only small numerical differences in these tested views, not general integration convergence across all anatomy or optimizer trajectories.

## 9. Freeze and independent audit

Before running or examining new evaluation outcomes, freeze the cohort manifests/indices, linkage statement, source/input hashes, target policy, seeds, algorithm configuration, analysis protocol, and exact runner/analysis code hashes. An independent code review checks physical coordinates, detector-centre resizing, Siddon implementation, unchanged optimizer renderer, target/candidate sharing, no ground-truth leakage into initialization, per-case seeds, exact metrics and aggregation. The old illustration cases may be used for data-loading and numerical smoke tests, but are not the ten selected development convergence cases and must not be used to tune evaluation performance.

The review and freeze receipt are recorded under `protocol/audits/` and `protocol/freezes/`; they do not require a new user approval for already authorized routine execution. If a bug is found, document it, fix it without outcome optimization, invalidate affected results and restart all affected matched methods. Preserve prior manifests and audit logs. If evaluation outcomes have already been inspected before a substantive change, disclose that fact and retain an untouched cohort/version for any later claim of independent validation.
