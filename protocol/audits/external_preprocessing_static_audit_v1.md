# External preprocessing static audit

Scope: read-only source/QC-record review on2026-10-26. No registration, synthetic outcome, GPU computation or effect estimate was inspected. This reviews `prepare_external_inputs.py`, retained `external_dedup.py`, source-unit/linkage evidence and the early source-only QC record. It does not replace the final60-case all-pairs duplicate audit or final assigned-list freeze.

**Conclusion: the coordinate, grid, label and intensity transformations match the declared plan. Final candidate deduplication and provenance closure remain pending.**

- Source files are checked against the download manifest before processing. CT must be3-D with finite invertible affine,1.5-mm-equivalent column norms and unknown/mm units. Each L1–L5 mask must match the CT shape and affine, be finite and binary, contain at least16voxels, not overlap another selected mask, and not touch any image face.
- The crop expands the five-label union by ceil(3mm/spacing) voxels and adjusts the world translation by the original affine times the crop offset. It does not resample voxel arrays. At1.5-mm spacing this is a two-voxel margin. Mean-centre translation uses the unweighted mean of five vertebral centroid positions, and the same source-grid coordinates feed labels, landmarks and the attenuation cache.
- The source CT data proxy applies NIfTI scaling when read. Derived values use float32 HU and `clip(HU−150,0,1800)` masked to the selected labels. The cache and metadata are independently loaded by the original `benchmark.load_case`, which checks centres, affine, expected geometry and preserved sampling. Zero motions in this input cache are a baseline coordinate scaffold; the later experimental motion must be generated and frozen separately.
- The unit assignment is transparent and restricted: original article DOI10.1148/ryai.230024 explicitly states all images were resampled to1.5-mm isotropic resolution; the selected source universe is its v1 adult IDs with revised v3 masks. Actual grid spacing is checked. Only derived copies receive the mm header; original files remain unchanged. This is inferred physical-unit provenance, not a claim that the released header itself specified mm. Preserve both the exact quotation and each original unit field.
- CT/seg grid fingerprints, exact hashes and morphology screening are computed before outcomes. Near-match/shape flags identify a review set. A negative screen cannot establish patient independence across scans or sources. Public metadata expose image_id only, so the current cautious sourceID/scans terminology is appropriate.

Required completion points:

1. **QC cache versioning:** the early-return path checks download/derived hashes but does not lock the QC implementation or criteria. Record SHA256 of the QC script, fingerprint implementation and a serializable criterion configuration; verify them before reusing a prior PASS. A later code change should trigger an explicit re-QC/versioned audit, not retain a stale decision silently.
2. **Complete pairwise audit:** early batches compared only with references available at their processing time. Before final assigned50 freeze, compare all completed candidate fingerprints against all old75 and all other candidates; retain the pair coverage matrix/counts. Do not interpret an early PASS as complete cross-candidate deduplication.
3. **Quarantine disposition:** `anatomically_ambiguous` means all10 centroid-pair distances differ by≤0.75mm and vertebral volumes by≤5%; `near_duplicate` is an image-similarity flag. Neither proves the same patient. Resolve or conservatively exclude suspicious scans under a predeclared source-QC rule, report reasons/counts and retain the flagged evidence. Do not call these confirmed patient duplicates. The final acceptance/exclusion rule must precede registration.
4. **Input-screen detail:** the script also requires strictly descending world-z L1–L5 centroids. Report this as a source-label/plausibility QC check, rather than proof that an unusual spine is invalid. Any rejection by this rule should be visible and adjudicated without registration outcomes.
5. **Freeze closure:** record source DOI/release, authoritative candidate-order file/hash, original units, corrected derived-unit basis, explicit label mapping, crop/centering, all derived hashes, and immutable assigned case_index0..49. Old and new seed bases differ as specified by the protocol. Full patient linkage remains unverified even after content screening.
